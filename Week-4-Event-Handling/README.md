
# Week 4: Java Event Handling

This folder contains practical Java Swing demonstrations of event handling.

## Demonstrations

1. ButtonClickDemo - Button click events.
2. CheckBoxDemo - Checkbox selections.
3. ComboBoxEventDemo - Combo box selections.
4. FocusListenerDemo - Component focus changes.
5. KeyListenerDemo - Keyboard events.
6. ListSelectionDemo - List selection events.
7. MenuEventDemo - Menu actions.
8. MouseListenerDemo - Mouse events.
9. MouseMotionListenerDemo - Mouse movement and dragging.
10. RadioButtonDemo - Radio button selections.
11. SliderEventDemo - Slider changes.
12. TextFieldEventDemo - Text field actions.
13. WindowListenerDemo - Window events.

## Concepts Covered

- ActionListener
- ItemListener
- KeyListener
- MouseListener
- MouseMotionListener
- FocusListener
- ListSelectionListener
- ChangeListener
- WindowListener

## How to Run

Compile all Java files:

    javac *.java

Run an individual demonstration:

    java ButtonClickDemo

Replace ButtonClickDemo with another class name to run a different demonstration.
